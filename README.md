# 轨道线维基 · Refraction Railway Wiki

一个面向《边狱公司》（Limbus Company）折射轨道玩家的配队与逐回合轴记录工具。

它不是普通的 Boss 图鉴，而是用于记录一整条折射轨道攻略：从分区部署、首发与替补顺序，到每回合使用的人格技能、E.G.O、硬币结果、七罪资源、阵亡情况和线路专属选择，最终形成可复查、可分享的完整战斗档案。

> 非官方同人项目，与 Project Moon 无关。游戏名称、设定与相关素材版权归其权利人所有。

## 项目解决什么问题

折射轨道 4～6 号线包含连续战、分区换队、链式替补、跨区资源继承以及大量线路专属机制。普通表格很难同时表达这些信息，也容易把区段内的连续站点错误地当成独立战斗。

本项目按照实际线路流程建模：

- 4号线：4 个连续战区段
- 5号线：3 个连续战区段
- 6号线：5 个连续战区段
- 每份档案记录整条线路，而不是把各区段拆成不同档案
- 区段内保持连续回合，区段间保留七罪资源和规定的 HP/SP 状态
- 前端负责编辑与即时计算，后端重新校验关键数据，避免保存伪造结果

## 主要功能

### 队伍与连续战

- 按区段编成 12 人队伍，自由调整部署顺序
- 部署顺序自动决定首发与链式替补次序
- 每名罪人只能部署一个人格
- 可为各区人格设置 Lv.1～60
- 记录每回合阵亡，并自动安排下一名替补入场
- 记录区段结束时每名罪人的 HP 百分比与 SP
- 自动处理 5号线和 6号线的区段禁用人格规则
- 6号线第五区按罪人继承第一区结束状态

### 技能、硬币与拼点

- 选择人格基础技能、防御技能及条件变体
- 每枚硬币分别选择正面或反面
- 显示逐枚硬币结算点数、最终攻击点数和拼点点数
- 人格等级、技能等级修正与线路增益自动进入攻防等级计算
- 支持基础威力、硬币威力、最终威力、拼点威力和额外等级差修正
- 支持攻击权重、实际目标数、硬币复用及完全共鸣顺序
- 识别反击、不可摧毁硬币、技能替换、随机武器、广域乱射和追加攻击等机制

### E.G.O

- 每个区段独立配置罪人的 ZAYIN、TETH、HE、WAW、ALEPH 装备
- 行动只能使用当前区段已装备的 E.G.O
- 支持四种释放路径：
  - 正常觉醒
  - 主动侵蚀（超频）
  - 选用 E.G.O 后触发的意外侵蚀
  - 回合开始时发生的强制侵蚀
- 自动选择觉醒或侵蚀技能形态
- 自动计算理智消耗、侵蚀概率和七罪资源消耗
- 超频资源与理智消耗逐项按 1.5 倍向上取整
- 强制侵蚀要求使用前处于 -45 SP，且不会再次扣除释放理智
- 对无差别攻击、固定目标和随机目标给出提示

### 资源与状态

- 人格技能实际发动后获得对应七罪资源
- E.G.O 在回合开始时扣除资源并提示不足
- 七罪资源跨区段连续继承
- 人格阵亡后按 S1×1、S2×2、S3×3 获得对应资源
- 支持 Hermes、纠缠、充能、血餐等自定义专属资源账本
- 提供烧伤、流血、破裂、沉沦和震颤的基础结算工具

### 线路专属机制

#### 4号线

- 12 个部署位增益
- 人格等级、攻击/防御等级、入场理智、拼点和最终威力等修正
- 减算硬币人格的入场理智方向处理

#### 5号线

- 按真实站点池选择永久增益与苦难
- 校验跨站非法选择和重复增益
- 增益与苦难从下一站开始累计生效
- 接入伤害、威力、敌方等级、速度、体力和资源变化等可量化效果

#### 6号线

- 三次鳞粉物理/罪孽抗性选择与伤害倍率计算
- 罗生蝶过去、现在、未来三次终战被动封印
- 晚霞旅人的树液与蛾，包括攻击等级、完全共鸣伤害和 SP 回复
- 第四区与第五区事件可直接在对应回合勾选触发
- 光之树苗（金枝楼层）整线最多使用 2 次，同一种能力不能重复：
  - 宗教层 PIGRITIA
  - 哲学层 SUPERBIA
  - 社会科学层 MOROSITAS
  - 语言层 IRA
- 免费 E.G.O、敌方速度减半、3 回合攻防等级平均化、IRA 威力/伤害/吸血等效果已接入计算与校验

## 数据规模

当前内置：

- 185 个人格
- 803 个人格基础与变体技能
- 370 条人格战斗/支援被动
- 112 个 E.G.O
- 114 个觉醒技能形态
- 100 个侵蚀技能形态
- 112 条 E.G.O 被动

用户档案初始为空，不包含演示或伪造记录。

## 运行

需要 Node.js 18 或更高版本，无需安装第三方运行依赖。

```bash
npm start
```

启动后访问：

- 网站：<http://localhost:5173>
- API：<http://localhost:3000/api>

Windows 用户也可以使用项目提供的一键启动脚本。

## 测试

```bash
npm test
```

测试覆盖战斗计算、连续战结构、部署限制、HP/SP 与资源继承、E.G.O 装备、阵亡替补、5/6号线机制、光之树苗、人格等级、逐枚硬币及后端可信重算。

## API

- `GET /api/health`：服务状态与版本
- `GET /api/axes`：档案列表
- `GET /api/axes/:id`：档案详情
- `POST /api/axes`：保存并校验档案
- `GET /api/railways`：线路数据
- `GET /api/identities`：人格与技能数据
- `GET /api/egos`：E.G.O 数据
- `GET /api/data-version`：数据版本

## 数据来源

- 4～6号线中文译名与机制优先参考[边狱公司中文维基](https://limbuscompany.huijiwiki.com/wiki/折射轨道)
- 英文原名、人格、技能和 E.G.O 数据参考 [Limbus Company Wiki.gg](https://limbuscompany.wiki.gg/)
- 光之树苗能力参考灰机中文维基[光之树苗能力](https://limbuscompany.huijiwiki.com/wiki/光之树苗能力)
- 攻防等级参考 Wiki.gg 的 [Offense Level & Defense Level](https://limbuscompany.wiki.gg/wiki/Offense_Level)
- E.G.O 觉醒、侵蚀与超频规则参考 Wiki.gg 的 [E.G.O/Gameplay](https://limbuscompany.wiki.gg/wiki/E.G.O/Gameplay)
- 中文资料缺失时使用英文 Wiki、官方文本或可验证的实测资料，并保留英文名称作为对照

Wiki 数据请遵守对应站点的署名与许可要求。本项目中的机制摘要不应被视为游戏官方说明；若游戏更新导致规则变化，欢迎提交 Issue 或修正建议。

## 当前限制

- 部分复杂状态效果仍以条件计算和机制提示为主，不是完整战斗模拟器
- Boss 专属阶段转换和随机目标不会自动预测
- HP 以百分比记录，尚未按人格等级重新计算具体最大 HP
- 数据可能随游戏版本更新而发生变化
